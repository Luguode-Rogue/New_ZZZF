# 攻城落点「碰撞地面」完整链路与诊断日志

> 目标：整理 ProjectileTrajectorySystem 攻城武器自动追落点视角中，
> **从弹道输入到最终落点贴地** 的整条链路，标注每一步 API、已知坑、以及新增的诊断 log 标签。
> 用于排查"镜头飞到的落点不对 / 碰撞地面做的有问题"。

整理日期：2026-08-06

---

## 一、完整链路（数据流向）

```
[1] 输入采集  PlayerTrajectorySystem.UpdateSiegeWeapon(siege)
      ↓ SiegeWeaponHelper.GetProjectileStartPosition(siege)  → Vec3 startPos (世界坐标，弹丸出口节点)
      ↓ SiegeWeaponHelper.GetShootingDirection(siege)       → Vec3 shootDir (引擎 ShootingDirection，未必单位向量)
      ↓ SiegeWeaponHelper.GetShootingSpeed(siege)           → float speed
      ↓ SiegeWeaponHelper.GetSiegeAirFriction(siege)        → float airFric
      → SetSiegeType(...) → ComputeSiegeLandingPoint(...) → SetLandingPoint(...)

[2] 弹道积分 + 逐段射线  ComputeSiegeLandingPoint(startPos, dir, speed, airFric)
      · 方向校验：零向量/NaN → return Vec3.Invalid
      · 归一化 dir = direction.NormalizedCopy()
      · for i in 0..499:
          next = TrajectoryPhysics.CalculatePosition(pos, dir, speed, dt=0.02, airFric)
          seg = next - pos
          if i >= 3:   // 起步前3步忽略命中，防止射线打中武器自身（自命中）
              Scene.RayCastForClosestEntityOrTerrain(pos, next, out hitDist, out hitPoint, out _, 0.1f)
              if hitDist < segLen && IsFinite(hitPoint):
                  → return SnapToGround(hitPoint)   // 命中即停
          pos = next
          if pos.z < -50: break
      · 500 步无命中 → return Vec3.Invalid

[3] 贴地  SnapToGround(point)
      p = point; p.z += 0.2; p.z = clamp(p.z, 0, 40)
      WorldPosition wp = new WorldPosition(Mission.Current.Scene, p)
      Vec3 snapped = wp.GetGroundVec3()   // ← 关键：返回 Vec3，吸附真实地形高度
      if IsFinite(snapped): return snapped
      catch: return point

[4] 回填 + 飞行  SkillSystemBehavior.SiegeLanding
      SetLandingPoint(snapped) → _cachedLandingPoint = snapped; _hasLandingPoint = true
      Toggle() → StartFlyingOut() → BuildViewFrame(_cachedLandingPoint)
          eye = (target.x + Sin(bearing)*dist, target.y - Cos(bearing)*dist, target.z + height)
          _camera.LookAt(eye, target, Up) → _toFrame
      Tick(): LerpFrame(from, to, t) → _currentFrame (FlyingOut)
              _currentFrame = _toFrame (Holding)
      _currentFrame.origin = 相机最终飞到的眼睛位置
```

## 二、关键 API 与已知坑

| 环节 | API | 坑 |
| --- | --- | --- |
| 起点 | `SiegeWeaponHelper.GetProjectileStartPosition` | Mangonel/Trebuchet 返回 `projectile_leaving_position` 节点 **GlobalPosition**（世界坐标）；Bombard/Catapult 返回 `position`（也可能是世界坐标）。需确认起点就在炮口。 |
| 方向 | `SiegeWeaponHelper.GetShootingDirection` | 反射引擎 `ShootingDirection`，**未必是单位向量**，必须 `NormalizedCopy()`。零向量归一化 → NaN。 |
| 弹道 | `TrajectoryPhysics.CalculatePosition(pos, dir, speed, dt, airFriction)` | 方向必须归一化；空气摩擦可能让速度衰减。 |
| 射线 | `Scene.RayCastForClosestEntityOrTerrain(pos, target, out dist, out hit, out ent, 0.1f)` | ① `out hit` 未命中时**未初始化**，可能含 NaN，必须 IsFinite 校验；② **起点在武器体内时第一帧就命中武器自身** → 落点落在脚下（核心 bug，用 i>=3 跳过）；③ 只接受 `hitDist < segLen` 的段内命中。 |
| 贴地 | `WorldPosition.GetGroundVec3()` | **有返回值 Vec3**，必须 `Vec3 v = wp.GetGroundVec3()`。没有 `.Position`、没有 `.GetVec3()`。定义在 `TaleWorlds.Engine`，不是 `TaleWorlds.Core`。 |
| 飞行 | `BuildViewFrame` + `LerpFrame` + `LookAt` | `BuildViewFrame` 内又用 `Scene.GetGroundHeightAtPosition` 对 target 做地面高度（仅地形，不含实体）。落点经 SnapToGround 已贴地，此处再次贴地属冗余但无害。 |

## 三、诊断 Log 标签（搜索关键字）

所有 log 前缀统一为 `[SiegeLanding]`，按阶段细分：

| 标签 | 含义 | 期望 |
| --- | --- | --- |
| `[SiegeLanding][IN]` | 输入参数 start/dir(len)/speed/airFric | dir.len 明显 > 0 |
| `[SiegeLanding][OUT]` | 最终落点 | 合理世界坐标，非 Invalid |
| `[SiegeLanding][Compute] start loop` | 归一化方向、速度 | dir(n) 为单位向量 |
| `[SiegeLanding][Compute] bad direction` | 方向为零/NaN | 不应出现 |
| `[SiegeLanding][Compute] NaN at step i` | 积分出 NaN | 不应出现 |
| `[SiegeLanding][Compute] HIT at step i` | 命中：hitDist/segLen/hitPoint | hitDist < segLen；若 i<3 说明自命中 |
| `[SiegeLanding][Compute] hitPoint non-finite` | 命中但坐标 NaN | 不应出现 |
| `[SiegeLanding][Compute] fell out of world` | 掉出世界 z<-50 | 说明弹道没命中任何东西 |
| `[SiegeLanding][Compute] no hit in 500 steps` | 500 步无命中 | 速度太低/方向朝上 |
| `[SiegeLanding][Snap] in` | 贴地前命中点 | — |
| `[SiegeLanding][Snap] out` | 贴地后坐标 + wp.valid | out 与 in 的 z 应接近地形高度 |
| `[SiegeLanding][Snap] snapped non-finite` | 贴地失败退回 | 不应出现 |
| `[SiegeLanding][Snap] exception` | GetGroundVec3 抛异常 | 多为 Scene 无效 |

## 四、本次针对"碰撞地面不对"做的修正

1. **起步自命中过滤**：`ComputeSiegeLandingPoint` 循环内 `i >= 3` 才接受射线命中。
   原因：弹丸起点（炮口节点）常与武器实体重叠，第一步射线就打中炮体，`hitDist` 极小，
   落点被误判为武器脚下 → 镜头飞到脚下而非真正落点。跳过前 3 步给弹丸"出膛"空间。

2. **贴地统一用 `GetGroundVec3()` 返回值**（此前误写成 `.Position`/`.GetVec3()`，编译不过）。
   修正：`Vec3 snapped = wp.GetGroundVec3();`

3. **链路全环节 log**：从 `[IN]` 输入到 `[Snap] out` 逐环节打印，便于直接定位
   "是方向算错 / 积分发散 / 自命中 / 贴地失败" 哪一步出问题。

---

## 五、排查建议（按 log 顺序）

1. 先看 `[IN]` 的 `dir(len)`：若 len≈0 → 武器未瞄准，落点 Invalid 属正常。
2. 看 `[Compute] HIT at step` 的 `i`：若 `i` 很小（0~2，理论上已被 i>=3 拦掉）或 `hitDist` 极小 → 仍可能自命中，需调大跳过步数。
3. 看 `[Compute] no hit in 500 steps` → 速度/方向导致弹道飞出或上飘，需核对 `GetShootingSpeed` / `GetSiegeAirFriction` 取值是否合理。
4. 看 `[Snap] in` vs `out`：若 `out` 与 `in` 的 (x,y) 一致仅 z 下降 → 正常贴地；若 (x,y) 也偏移 → `GetGroundVec3` 在无效 scene 下异常。
5. 若 `[OUT]` 打印 Invalid → 相机系统收到的落点无效，镜头不会切换（对应 Toggle 里的"落点无效"提示）。
