# 自建武器飞弹：模型与轴向参考

记录日期：2026-10-02。当前实现：灵魂弹幕。源码目录为 Mod 根目录下的 工程/New_ZZZF；本文在 工程/文档/技术参考。

## 竖着飞的原因

SpellProjectileMissionLogic 原先使用 Mat3.CreateMat3WithForward(direction) 直接设置实体朝向。这个接口把模型本地 forward（+Y）轴对准飞行方向，并保留 up（+Z）轴作为上方。箭矢等武器模型的长度沿本地 +Z，因此模型看起来仍竖着，尽管实际位移方向正确。

## 当前校正

SpellProjectileRequest 增加 VisualPitchOffset（弧度），默认 0，供每个技能单独选择模型的轴向校正。灵魂弹幕设置 -1.5707964f，即绕模型本地 side 轴旋转 -90 度。

统一函数 GetVisualRotation(direction, request)：

```csharp
Mat3 rotation = Mat3.CreateMat3WithForward(direction);
if (request.VisualPitchOffset != 0f)
    rotation.RotateAboutSide(request.VisualPitchOffset);
return rotation;
```

按 Mat3.RotateAboutSide 的实现：u_new = u_old*cos(a) - f_old*sin(a)。当 a = -PI/2 时，u_new = f_old，因此模型本地 +Z（箭尖轴）沿飞行方向。

生成、每帧飞行更新、穿透场景截断三个设置实体朝向的入口都调用此函数。不能只在生成时旋转，否则后续追踪更新会覆盖校正。逻辑 Direction 独立保留，移动及碰撞不读取已校正的实体 forward，避免模型旋转改变真实弹道。其他技能默认偏移为 0。

不同资源的箭尖轴可能不同；此值不是所有模型的通用固定答案。若资源沿 -Z，需对应反向校正；若资源已沿 +Y，则使用 0。当前方向的实际观感待玩家复测。

## 模型获取

原版 MissionWeapon.GetWeaponData(false) 通过视图回调提供 MetaMesh 类型的 FlyingMesh 和 WeaponMesh。优先 FlyingMesh，缺失时使用 WeaponMesh，以支持投掷物、复合模型及锻造部件。不要把物品 MultiMeshName 当作单 Mesh 资源用 Mesh.GetFromResource 读取。

灵魂弹幕每次施法提取一次 MetaMesh。SpellProjectileRequest.VisualMesh 提供模型快照；管理器用 entity.AddMultiMesh(request.VisualMesh.CreateCopy(), true) 为每枚弹体生成独立外观副本。

弓弩优先取当前 AmmoWeapon；其次从装备中找与 AmmoClass 匹配的箭或弩矢；无装备弹药时从相应物品定义提取外观，不新增扣弹药逻辑。投掷武器直接取自身的 WeaponData。

## 同一目标的弧线路径

灵魂弹幕使用 targetShotIndex = projectileIndex / targetCount 区分同目标第几枚。首枚沿目标方向；后续飞弹在该方向的侧轴/上轴平面分散发射，按 2.3999632 弧度步进区分方位，再通过现有追踪转向和短暂 HomingDelay 弯向目标。近距离缩小散开幅度及延迟。这是实际弯曲弹道，不是仅挪动外观。
