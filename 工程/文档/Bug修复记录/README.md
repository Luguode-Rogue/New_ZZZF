# Bug 修复记录

本目录保存原始 Bug 修复文档。**不要因为已经建立统一经验库而删除这里的原始文件。**

统一检索入口：[历史/BUG_HISTORY.md](../历史/BUG_HISTORY.md)

原始记录的价值在于保留真实日志、失败尝试、版本条件和排查顺序，这些内容在以后复现同类问题时比单独的最终结论更重要。

整理规则：

1. 新 Bug 先在这里保留完整原始记录。
2. 修复完成后，在 `历史/BUG_HISTORY.md` 增加分类与关键词入口。
3. 已证明长期有效的技术结论再提升到 `功能/` 或 `技术参考/`。
4. 原始排错过程永不因为“已经总结过”而删除。
