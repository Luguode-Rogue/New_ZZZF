# New_ZZZF 项目文档

## 当前定位

New_ZZZF 是一个持续扩展的 Bannerlord Mod 工程，包含技能系统、TacticalMap、UI/HtmlUI、SpellForge、世界状态继承等多个功能方向。

> 注意：旧版 README 的主体内容描述的是 ProjectileTrajectorySystem，已经与当前工程不一致。当前项目入口应以 `工程/文档/README.md` 与各功能主文档为准。
