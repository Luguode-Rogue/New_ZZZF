# New_ZZZF 测试指南

## 通用生命周期测试

所有带 UI、MissionBehavior、WebView 或输入接管的功能都至少测试：

- 首次打开
- 重复打开
- 正常关闭
- 重复关闭
- Esc / 热键关闭
- 场景切换
- 战斗结束
- Alt-Tab / 窗口失焦
- 异常初始化后的再次打开

## 输入与焦点

尤其检查：

- UI 是否真的获得预期输入模式
- 鼠标是否被 UI 吃掉
- 键盘 Esc 是否仍可关闭
- 与原生 UI 按键是否冲突
- WebView 失焦后是否继续遮挡或接收输入

## 性能

- 不在每帧输出常规状态日志。
- 动态扫描与 UI 绘制分别计时/节流。
- 高人数战斗与低人数战斗都测试。
- 开关关闭后应真正停止对应工作，而不是只隐藏 UI。

## 兼容性

涉及 Bannerlord 版本差异时必须记录具体版本、API、现象和 fallback，并回写 `技术参考/` 与 `历史/BUG_HISTORY.md`。

## Bug 回归

任何已经修复的 Bug 都应成为回归测试项。不要只验证“现在不报错”，还要验证导致问题的原始触发路径已经失效。
