# New_ZZZF 项目架构

## 总体原则

项目按功能模块、运行时核心、UI 表现、配置/兼容和历史资料分层。功能主文档描述现行行为；历史资料保存设计演变和排错过程。

## 主要功能

- TacticalMap：战术地图、Terrain、Tracking、Order、Camera、HtmlUI。
- 技能系统：技能数据、运行时效果、触发调度、UI、持久化与兼容。
- SpellForge：法术锻造。
- 世界状态继承：跨存档/新世界状态持久化。

## UI 原则

HtmlUI / Gauntlet 属于表现层。UI 不直接承担 Mission 核心状态，不应复制独立的业务逻辑。

## 兼容原则

版本敏感 API、私有字段和反射调用集中隔离，必须有失败兜底。不同 Bannerlord 版本的类型和方法差异不得散落在业务代码中。

## 生命周期

初始化、Mission 开始、Mission Tick、UI 生命周期和 Mission 结束必须有明确的所有权；重复初始化与重复注册必须具备幂等保护。

## 日志

高频日志默认关闭。仅在专项排查时临时提高级别，避免每帧日志污染排错材料。
