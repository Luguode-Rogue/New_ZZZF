## 按问题快速定位

### 页面能打开但点不到

先查：

`BUG_HISTORY.md` → UI / HtmlUI → 输入/焦点/层级 → 原始排错

### 页面自动关闭、闪烁、焦点异常

先查：

`BUG_HISTORY.md` → HtmlUI 生命周期 / 输入模式 / 窗口显隐 → 原始 HtmlUI 排错

### MissingMethodException / MissingFieldException

先查：

`技术参考/` → API 迁移/版本兼容 → `BUG_HISTORY.md` → 原始异常记录

### TacticalMap 地图比例、地形或追踪异常

先查：

`功能/TacticalMap.md` → TacticalMap 审计 → Bug 经验库

### 技能系统出现存档、UI、触发器异常

先查：

`功能/技能系统.md` → Bug 经验库 → 对应技能系统原始记录

### 改完之后怀疑回归

先查：

`项目文档/TESTING_GUIDE.md` → 对应功能专项测试 → 原始回归记录

## 文档可信度规则

当前代码与最近一次实机验证是最高优先级事实来源。

现行主文档用于说明“现在应该怎么做”。

历史审计、工作日志、Bug/Postmortem、旧计划用于说明“为什么曾经这样做”，不能单独覆盖当前代码事实。

## Bug 经验规则

统一入口只保存分类、关键词、当前结论和原始记录位置；完整排错过程必须保留在原始文件中：

`现象 → 触发条件 → 日志/堆栈 → 初始假设 → 排查过程 → 失败方案 → 失败原因 → 根因 → 修复 → 验证 → 版本/API 条件`

禁止为了压缩文档而删除失败方案。
