## 使用原则

示例用于复用实现模式，不代表当前所有技能的唯一正确实现。使用示例前先确认当前技能主文档与实际代码接口；遇到版本/API 差异时优先查 API 迁移记忆库与 Bug 经验库。

原始示例可能包含特定时期的实现细节，不能因为示例曾经可用就默认适用于所有 Bannerlord 版本。
