## 3. 测试流程

### 3.1 冒烟测试（每次构建后）

1. 启动游戏，检查 MCM 面板是否正常显示
2. 开始新游戏，检查是否自动导入（无 Legacy.json 时正常启动）
3. 保存游戏，检查 `Legacy.json` 是否生成
4. 拨动«手动导出»，检查文件是否更新

### 3.2 完整测试（版本发布前）

1. 执行上述所有测试用例
2. 测试多轮导出-新游戏-导入-导出循环
3. 测试不同存档之间的独立性
4. 检查构建零错误

## 4. 通过标准

- 所有 P0 用例通过
- P1 用例通过率 ≥ 90%
- 无游戏崩溃或存档损坏
- 日志无异常错误信息
