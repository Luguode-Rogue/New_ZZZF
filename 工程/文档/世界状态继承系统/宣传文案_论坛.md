## 正文

各位领主好，

我是 New_ZZZF Mod 的 contributor。今天单独给大家介绍其中一个子系统：**世界状态继承系统（LegacyWorld）**。

一句话概括：**它让你的帝国在开新档时继续存在。**

### 为什么需要它？

传统 Bannerlord 流程里，你花几十个小时统一了卡拉迪亚，存档一结束，下一局新游戏又是一张完全随机的地图。王国、家族、领地，全没了。

LegacyWorld 改变这件事：

```
存档A（帝国统一卡拉迪亚）
   ↓ 保存时自动生成世界遗产 → Legacy.json
新游戏
   ↓ 自动应用遗产
"继承世界" —— 版图、家族、王国结构延续上一局
```

**新游戏不是重新开始，而是旧世界的下一个时代。**

### 它能继承什么？

| 类别 | 说明 | 可单独开关 |
|------|------|-----------|
| 王国结构 | 统治者、宣战/和平状态 | ✅ |
| 家族数据 | 所属王国、等级、声望 | ✅ |
| 领地所有权 | 城镇/城堡/村庄归属 | ✅ |
| 家族经济 | 金币、影响力 | ✅ |
| 玩家人物遗产 | 你与队友以"游荡英雄"形式出现在新世界（遇到原来的自己） | 随存档累积 |

> ✨ **彩蛋功能**：你上一局的主角与队友，会以独立游荡英雄的身份出现在新世界——而且支持**跨世界遗产链**：A 局的自己 → B 局 → C 局，C 局里能同时遇到 A 和 B 留下的"原来的自己"。

### 它怎么用？

0 配置开箱即用：

- **自动导出**：保存游戏时，自动把当前世界状态写入 `Legacy.json`
- **自动导入**：仅在你「开始新游戏」时触发（载入旧存档**不会**触发，绝不污染已有进度）
- **手动控制**：MCM 面板提供「手动导出」「手动应用」按钮，拨一下即触发
- **防呆机制**：同世界检测（禁止把同一局的遗产导入自己）、每局只导入一次（`applied` 标志）

所有开关在游戏内 **Mod Options → New_ZZZF → LegacyWorld** 面板，修改即时生效，**无需重启**。

### 设计边界（诚实说明）

以下**当前版本不继承**，保持政治格局纯粹、避免冲突：

- 英雄/玩家的装备、部队、家族从属关系（仅以"游荡英雄"模板形式出现）
- 物品/装备
- 外交战争细节状态

> ✅ 但你的主角与队友会以**独立游荡英雄**身份出现在新世界（"遇到原来的自己"），且支持跨世界遗产链累积。
> ✅ 本存档内**不会出现自己/队友的二重身**——只会在一个全新存档里遇到"原来的自己"。
> ✅ 已复刻的世界持久化记录，重开游戏也不会重复刷出。

我们专注把"政治格局"这一层做扎实。

### 当前版本

**v0.6.0** —— 玩家人物遗产独立存储（LegacyHeroes.json）+ 跨世界累积遗产链 + 防本存档二重身 + 已复刻世界持久化防重复。

支持 Bannerlord **v1.2.x**。

### 获取方式

作为 New_ZZZF Mod 的子系统提供，安装后在 MCM 中启用即可。

## FAQ（建议楼主自占楼）

**Q：会覆盖我正在玩的存档吗？**
A：不会。自动导入只在「开始新游戏」时触发；载入已有存档完全不触发。

**Q：导入会不会重复执行？**
A：不会。每个存档通过 `applied` 标志保证整局只导入一次。

**Q：我想完全随机的新世界怎么办？**
A：MCM 主开关关掉「启用世界状态继承系统」即可，零影响。

**Q：支持旧版遗产文件吗？**
A：当前版本基于 v0.4.0 数据结构；同世界检测会阻止把同一 Campaign 的遗产导入自身。

**Q：性能影响大吗？**
A：导入/导出均在 100ms 内完成，无感知。
