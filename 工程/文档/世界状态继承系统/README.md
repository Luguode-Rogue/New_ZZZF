# 世界状态继承系统 (World State Legacy)

## 概述

世界状态继承系统是 New_ZZZF Mod 的一个子系统，代号 **LegacyWorld**。

它允许玩家在一个 Campaign 存档中生成"世界遗产档案"，记录当前世界的政治状态（城镇归属、王国结构、家族关系等），并在下一局新游戏开始时将这些历史状态重新注入新世界，使新世界成为旧世界的"平行历史"。

## 核心理念

> 新游戏不是重新开始，而是旧世界的下一时代。

传统 Bannerlord 游戏流程：
```
存档A（帝国统一卡拉迪亚）
  ↓
结束
  ↓
新游戏 → 完全随机世界
```

LegacyWorld 流程：
```
存档A（帝国统一卡拉迪亚）
  ↓
生成世界遗产 → Legacy.json
  ↓
新游戏 → 自动应用遗产 → "继承世界"
```

## 触发时机

| 事件 | 行为 | 控制开关 |
|------|------|----------|
| `OnBeforeSaveEvent` | 自动导出世界状态到 `Legacy.json`；玩家人物累积写入 `LegacyHeroes.json` | MCM「启用世界状态继承系统」+「存档时自动导出」 |
| `OnNewGameCreatedEvent` | 自动导入世界遗产（**仅新游戏**，载入存档不触发） | MCM「启用世界状态继承系统」 |
| MCM 按钮「手动导出」 | 手动导出当前世界状态（世界状态 + 玩家人物） | 无条件 |
| MCM 按钮「手动应用」 | 手动强制应用遗产（忽略同世界检测） | 无条件 |

> **重要**：导入只在「开始新游戏」时自动发生。载入已有存档不会触发导入，避免污染已有进度。
> 已复刻过的遗产世界记录在 `LegacyHeroes.json` 的 `applied_world_ids` 中（持久化），重开游戏也不会重复复刻。

## 配置（MCM 设置菜单）

所有开关和操作通过游戏内置的 **Mod Options → New_ZZZF → LegacyWorld** MCM 面板进行。

### 基础控制

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| «启用世界状态继承系统» | 开关 | `开` | 主开关。关闭后完全禁用导入/导出，即使存在 `Legacy.json` 也不会触发。 |
| «存档时自动导出» | 开关 | `开` | 关闭后保存游戏不再自动生成 `Legacy.json`。 |
| «启用调试日志» | 开关 | `开` | 关闭后不再写入 `affix_debug.log`（运行时实时生效）。 |

### 导入数据类别

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| «恢复王国结构» | 开关 | `开` | 导入王国统治者、宣战/和平状态等。 |
| «恢复家族数据» | 开关 | `开` | 导入家族所属王国、等级、声望等。 |
| «恢复领地所有权» | 开关 | `开` | 导入城镇/城堡/村庄的归属关系。 |
| «恢复家族经济» | 开关 | `开` | 导入家族金币、影响力数据。 |
| «创建缺失家族» | 开关 | `关` | 在新世界中不存在目标家族时自动创建（预留功能）。 |

### 操作按钮（拨动触发）

| 设置项 | 说明 |
|--------|------|
| «手动导出（拨动即触发）» | 将此开关拨动到「是」，立即导出当前世界状态到 `Legacy.json`（完成后自动复位）。 |
| «手动应用（拨动即触发）» | 将此开关拨动到「是」，立即将 `Legacy.json` 导入当前世界（完成后自动复位）。 |

> 面板中的所有开关均**无需重启游戏**，修改即时生效。
> 设置数据持久化在 `Modules\New_ZZZF\Settings\LegacyWorldSettings.xml`。

## 日志

调试日志统一写入**模块根目录**下的 `LegacyWorld.log`（与 `SubModule.xml` 同级）。
每次游戏启动会清空旧日志并写入新文件。关键标签：`BEHAVIOR`、`SERVICE`、`KINGDOMIMP`、`CLANIMP`、`SETTLEIMPORT`、`HERO`、`VERIFY`、`EXPORT`、`IMPORT`。

## 数据存储文件

| 文件 | 位置 | 说明 |
|------|------|------|
| `Legacy.json` | 模块根目录 | 世界状态（王国/家族/定居点），覆盖写 |
| `LegacyHeroes.json` | 模块根目录 | 玩家人物遗产，累积写（跨世界遗产链） |
