# 版本路线图

## 已完成版本

| 版本 | 日期 | 主要特性 |
|------|------|----------|
| ✅ **v0.1.0** | 2026-07-18 | 项目初始化、数据模型、导出系统、JSON 序列化 |
| ✅ **v0.2.0** | 2026-07-20 | 导入框架、适配器系统、IGameAdapter 接口 |
| ✅ **v0.3.0** | 2026-07-22 | Campaign 运行时集成、Save/Load 事件驱动、防重复导入 |
| ✅ **v0.4.0** | 2026-07-23 | MCM 设置菜单、XML 持久化、触发时机修正、废弃 JSON 配置 |

## 规划中

### v0.5.0 — 健壮性增强

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 导入容错 | P1 | 单个 Kingdom/Clan 导入失败不影响其他 |
| 数据校验 | P1 | 加载 Legacy.json 时检查完整性 |
| 日志增强 | P2 | 导入详情统计更完善 |
| 边界处理 | P2 | 空世界、残缺 JSON、缺失 ID 处理 |
| 性能优化 | P3 | 大批量数据导入速度优化 |

### v1.0.0 — 正式版

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 发布版稳定性 | P0 | 经过充分测试，无已知崩溃 |
| 国际化支持 | P2 | MCM 面板支持多语言 |
| 性能基线 | P1 | 1000+ 元素导入 < 500ms |

## 长期展望

| 特性 | 说明 |
|------|------|
| 英雄状态继承 | 跨越存档保留英雄关系、技能、等级（需解决 ID 冲突） |
| 外交关系继承 | 继承战争/和平状态、联盟关系 |
| Mod 兼容性 | 与其他大型 Mod（如 BannerKings）兼容 |
| 选择性导入 UI | 在 MCM 面板中更精确地选择需要导入的元素 |
| 多档案管理 | 支持多个 Legacy.json 档案，可选择加载哪个 |
